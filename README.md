# IMDb Top 1000 Movies - Data Visualization

Python project to analyze IMDb Top 1000 movies dataset.

## How to Run
1. Install libraries: `pip install -r requirements.txt`
2. Run code: `python visualization.py`
3. Check charts: Open `charts` folder

## Charts Generated
1. **Top 10 Genres**: Most common movie genres
2. **Rating Distribution**: IMDB rating spread  
3. **Release Year**: Movies per year

## Tech Stack
Pandas, Matplotlib, Seaborn, Python
